## Novidades da versão

- Núcleo Java de biblioteca: cadastro, consulta, disponibilidade, empréstimos, devoluções, multa de **R$ 2,00 por dia** e relatórios.
- Conformidade com o exercício: **POO, funções puras, imutabilidade, Streams filter/map/reduce**, implementação imperativa equivalente e testes.
- Interface Next.js 16 e Design System INKO, catálogo editorial e landing de apresentação.
- Backend modular: Gateway FastAPI com proteção de capacidade e quatro microsserviços Java/Spring Boot com PostgreSQL/Flyway.
- Login real de operadores, hash BCrypt, sessões revogáveis e cookie HttpOnly no BFF.
- Upload validado de capas com persistência em volume Docker ou PostgreSQL, conforme ambiente.
- Carga acadêmica prevista no piloto com **505 edições, 36 leitores fictícios e 60 empréstimos demonstrativos**.
- README expositivo com **arquitetura, DER e UML em Mermaid**, trechos de código Java e guia para responder perguntas sobre o projeto.

## Entrega acadêmica

A equipe entrega projeto no GitHub, README e testes (**3,0 pontos**). Cada integrante também entrega **dois diagramas e cinco respostas feitos à mão, em papel A4 branco, presencialmente ao professor**. Na apresentação (**2,0 pontos**), cada aluno responde individualmente a uma pergunta sobre o código.

As imagens GHCR são publicadas pelo pipeline apenas após testes e verificação de todos os componentes.
